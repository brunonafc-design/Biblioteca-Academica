# Biblioteca Acadêmica

## Sobre o projeto

Projeto acadêmico desenvolvido na disciplina de Modelagem de Dados do curso de Análise e Desenvolvimento de Sistemas (ADS).

O objetivo é desenvolver um banco de dados relacional para gerenciar os empréstimos de uma biblioteca acadêmica, contemplando o cadastro de leitores, livros, autores, exemplares físicos e o controle de empréstimos.

## Objetivos

- Aplicar conceitos de modelagem de dados relacionais.
- Desenvolver um Modelo Entidade-Relacionamento (MER).
- Implementar tabelas, chaves primárias e estrangeiras.
- Aplicar regras de integridade e restrições.
- Realizar inserções, consultas e manipulação de dados utilizando SQL.

## Tecnologias utilizadas

- MySQL
- MySQL Workbench
- SQL

## Estrutura do banco de dados

O banco de dados é composto por sete tabelas:

- `LEITOR`
- `LIVRO`
- `AUTOR`
- `EXEMPLAR`
- `EMPRESTIMO`
- `ITEM_EMPRESTIMO`
- `LIVRO_AUTOR`

## Funcionalidades

- Cadastro e gerenciamento de leitores.
- Cadastro de livros e autores.
- Controle de exemplares físicos.
- Registro de empréstimos.
- Associação de livros e autores.
- Consultas para obtenção de informações do acervo e dos empréstimos.

## Contexto acadêmico

Este projeto foi desenvolvido como atividade acadêmica, com foco na aplicação prática dos conceitos de modelagem de dados e banco de dados relacionais.
